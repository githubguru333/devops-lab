# DevOps Lab

A hands-on DevOps, Cloud, SRE, and Platform Engineering laboratory.

This repository documents my practical learning journey, experiments, infrastructure projects, troubleshooting exercises, and production-oriented implementations.

The goal is to build strong practical skills by designing, implementing, breaking, troubleshooting, documenting, and improving real-world infrastructure and DevOps environments.

---

## 🎯 Objectives

- Build production-oriented DevOps skills through hands-on implementation
- Transition from Linux System Administration into DevOps / Cloud / SRE / Platform Engineering
- Learn cloud infrastructure and automation using real-world scenarios
- Practice Infrastructure as Code and configuration management
- Develop Kubernetes and OpenShift administration skills
- Build CI/CD pipelines
- Implement monitoring, observability, and reliability practices
- Document troubleshooting and operational lessons
- Build a portfolio of practical engineering projects
